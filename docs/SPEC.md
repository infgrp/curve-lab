# 곡선 찾기 실험실 — 명세서 (SPEC)

기호: 학습용 점 \((x_i, y_i)\), \(i=1,\dots,n\). 손실은 평균제곱오차(MSE)
\[
L = \frac{1}{n}\sum_{i=1}^{n}\bigl(\hat y_i - y_i\bigr)^2 .
\]

## 0. 데이터 생성 (`src/core/data.ts`)

| 항목 | 값 | 비고 |
|---|---|---|
| 참 함수 | \(g(x)=\sin(2.5x)+0.3x\) | 화면에는 끝까지 보여 주지 않음(3단계 결과 화면에서만 선택적으로 표시) |
| 정의역 | \(x\in[-1,1]\) | 정규화된 좌표. 학습 안정성을 위해 이 범위를 유지 |
| 학습 점 수 | \(n=12\) | |
| 학습 점 x | 등간격 격자 \(-1,\dots,1\)에 ±(간격의 30%) 균등 흔들기 | 양 끝을 반드시 덮게 하여 외삽을 막음 |
| 잡음 | \(\varepsilon\sim N(0,\sigma^2)\), \(\sigma=0.25\) | Box–Muller, 시드 난수 |
| 검증(숨김) 점 | 40개, \(x\sim U[\min x_i,\max x_i]\) | **학습 점 범위 밖에 두지 않는다**(아래 근거 참조) |
| 시드 | 세션마다 새 시드, 교사 설정에서 고정 가능 | |

**근거.** `reference/overfit_experiment.py`로 한 사전 실험(Python/NumPy, 시드 20개, Adam lr=0.01, 20000 epoch)의 결과는 다음과 같다.

| 학습점 n, σ | 뉴런 2 | 뉴런 8 | 뉴런 64 | 잡음 하한 σ² |
|---|---|---|---|---|
| 12, 0.25 (평균 / 중앙값) | 0.265 / 0.120 | **0.097 / 0.093** | 0.130 / 0.110 | 0.0625 |
| 8, 0.25 (평균 / 중앙값) | 0.259 / 0.121 | 0.120 / 0.105 | 2.633 / 0.143 | 0.0625 |

- n=12, σ=0.25에서 평균과 중앙값 모두 "작음 → 적당 → 큼"의 U자형이 나타났다. 다만 그 차이는 크지 않다(0.093 대 0.110). 따라서 과적합은 숫자보다 **곡선 모양**(64개 뉴런의 곡선이 점마다 꺾이는 모습)으로 보여 주는 것이 주된 전달 수단이다.
- n=8의 평균 2.633은 검증 점이 학습 점 범위 밖에 있을 때 외삽 오차가 폭발한 결과이다. 그래서 검증 점을 학습 점 범위 안으로 제한한다.
- 뉴런 2개는 평균과 중앙값의 차이가 크다. 이는 일부 시드에서 ReLU가 죽어(dead ReLU) 학습이 실패하기 때문으로 보인다. 숨길 일이 아니며, "다시 해 보기"로 결과가 달라지는 것을 보여 준다.
- **JS 구현 후 Phase 6에서 `scripts/experiment-overfit.ts`로 같은 실험을 재현하여 위 경향이 유지되는지 확인한다.** 유지되지 않으면 설정값을 조정하고 이 표를 갱신한다.

## 1단계: 직선 맞추기 (`src/core/linear.ts`)

모델 \(\hat y = a x + b\).

- 기울기
  \[
  \frac{\partial L}{\partial a}=\frac{2}{n}\sum r_i x_i,\qquad
  \frac{\partial L}{\partial b}=\frac{2}{n}\sum r_i,\qquad r_i=\hat y_i-y_i .
  \]
- 닫힌 해(검증용): \(a^*=S_{xy}/S_{xx}\), \(b^*=\bar y-a^*\bar x\). (\(S_{xx}=\sum(x_i-\bar x)^2\), \(S_{xy}=\sum(x_i-\bar x)(y_i-\bar y)\))
- 헤세 행렬 \(H=\frac{2}{n}\begin{pmatrix}\sum x_i^2 & \sum x_i\\ \sum x_i & n\end{pmatrix}\)은 상수이다. 고정 학습률 경사하강법은 \(0<\eta<2/\lambda_{\max}(H)\)일 때, 그리고 그때에만 수렴한다(\(H\) 양의 정부호 가정).
- UI
  - 슬라이더 2개(a, b)와 손실 값을 실시간으로 표시하고, 각 점의 잔차를 세로 선분으로 그린다.
  - 오른쪽 패널: (a, b) 평면의 손실 등고선(격자 계산, 로그 간격 등고선)과 현재 위치 점.
  - "기계에게 맡기기": 현재 위치에서 경사하강법을 시작해 경로를 애니메이션으로 그린다.
  - 학습률 선택지 3개: 작음(\(0.1\cdot\eta_{\max}\)), 적당(\(0.6\cdot\eta_{\max}\)), 너무 큼(\(1.1\cdot\eta_{\max}\), 발산 시연). 여기서 \(\eta_{\max}=2/\lambda_{\max}\)는 코드로 계산한다.
- 이 단계는 직선이므로 사인 곡선을 맞출 수 없다. 이것을 "직선으로는 한계가 있다 → 2단계로"라는 연결 문구로 쓴다.

**테스트:** (1) 기울기 유한차분 검사, (2) 적당한 η에서 GD가 닫힌 해에 1e-6 이내로 수렴, (3) 1.1·η_max에서 손실이 증가(발산), (4) λ_max 계산이 2×2 고유값 공식과 일치.

## 2단계: 꺾은선 더하기 (`src/core/hinge.ts`)

모델
\[
\hat y = a x + b + \sum_{k=1}^{K} s_k \,\max(0,\; x - t_k),\qquad K=3 .
\]

- **동치성(안내문과 테스트의 근거).** 은닉층 하나인 1입력 ReLU 신경망 \(\sum_k v_k\,\mathrm{ReLU}(w_k x+\beta_k)+c\)의 각 항은
  - \(w_k>0\)이면 \(v_k w_k\max(0,x-t_k)\) (\(t_k=-\beta_k/w_k\)),
  - \(w_k<0\)이면 \(\max(0,t_k-x)=\max(0,x-t_k)-(x-t_k)\)이므로 꺾은선 하나와 일차식,
  - \(w_k=0\)이면 상수
  
  로 바뀐다. 따라서 위 모델은 "은닉 뉴런 K개인 ReLU 신경망 + 직선 항"과 정확히 같은 함수족이다. 직선 항이 없는 순수 신경망은 이 함수족의 부분집합이다. 다만 꺾이는 점이 데이터 범위 밖에 있는 뉴런 하나는 데이터 범위 안에서 직선처럼 동작하므로, 뉴런을 하나 더 쓰면 직선 항을 흉내 낼 수 있다. 화면에서 "꺾은선 하나 = 뉴런 하나"라고 말할 수 있는 근거가 이것이다.
- 기울기: \(\partial \hat y/\partial s_k=\max(0,x-t_k)\), \(\partial \hat y/\partial t_k=-s_k\,\mathbf 1[x>t_k]\). \(x=t_k\)에서는 미분 불가능하므로 하위기울기 0을 쓴다.
- 초기값: 1단계에서 찾은 \((a,b)\), \(t_k\)는 \(-0.5, 0, 0.5\), \(s_k=0\).
- UI
  - 꺾이는 점마다 손잡이를 둔다. 좌우로 끌면 \(t_k\), 위아래로 끌면 \(s_k\)가 바뀐다(슬라이더도 함께 제공).
  - 각 꺾은선 성분을 옅은 색으로 따로 그리고, 그 합을 굵은 선으로 그린다.
  - "기계에게 맡기기": 같은 매개변수에 경사하강법(또는 Adam)을 적용한다. 꺾이는 점이 모든 학습 점의 오른쪽에 있으면 그 뉴런은 기울기가 0이 되어 움직이지 않는다. 이 현상을 숨기지 말고 "이 뉴런은 쉬고 있어요" 표시로 보여 준다.

**테스트:** (1) 유한차분 검사(꺾이는 점에서 떨어진 위치에서), (2) 임의의 (w, β, v, c)로 만든 ReLU 신경망과 변환한 꺾은선 모델이 무작위 x 1000개에서 1e-12 이내로 일치, (3) 학습 후 손실이 1단계 최적 직선의 손실보다 작거나 같음.

## 3단계: 신경망 학습과 숨겨진 점 (`src/core/mlp.ts`, `src/core/optim.ts`)

모델: 1 → H → 1, 은닉층 ReLU, 출력 선형. 전체 배치 학습.

| 항목 | 값 |
|---|---|
| 은닉 뉴런 수 선택지 | 2, 8, 64 |
| 초기화 | \(W_1\sim N(0,2)\) (입력 1개 기준 He), \(b_1=0\), \(W_2\sim N(0,2/H)\), \(b_2=0\) |
| 최적화 | Adam(lr=0.01, β₁=0.9, β₂=0.999, ε=1e-8). 안내문에는 "경사하강법을 개선한 방법"이라고 정확히 적는다 |
| 학습 횟수 | 20000 epoch, requestAnimationFrame마다 일정량(예: 200 epoch)씩 나누어 실행하며 곡선과 손실 그래프를 갱신 |

- 학습 중에는 학습 손실만 보여 준다. 학습이 끝나면 "숨겨진 점 공개" 버튼을 눌러 검증 점을 나타내고 검증 MSE를 계산한다.
- 점수: 검증 MSE를 그대로 쓰고, 잡음 하한 \(\sigma^2\)을 기준선으로 함께 표시한다. ("검증 점 자체에 잡음이 있어서 이보다 크게 낮추기는 어렵다." 단, 유한 표본이라 우연히 그보다 낮을 수는 있으므로 "불가능"이라고 쓰지 않는다.)
- 방문자 분포: 오늘 기록된 검증 MSE의 히스토그램 위에 내 위치를 표시한다(`src/ui/scoreboard.ts`, localStorage, 익명, 날짜별). 뉴런 수별 평균도 함께 보여 주면 U자형이 방문자 데이터로 드러난다.
- "다시 해 보기": 같은 데이터, 새 초기화 시드. 결과가 달라질 수 있음을 보여 준다.

**테스트:** (1) 역전파 기울기 유한차분 검사(모든 매개변수), (2) 시드가 같으면 결과가 비트 단위로 같음, (3) H=64, 20000 epoch에서 학습 MSE < 0.02, (4) Adam 한 스텝을 손으로 계산한 값과 일치.

## 4. 전체 흐름과 키오스크 요건 (`src/ui/app.ts`, `src/ui/idle.ts`)

- 시작 화면 → 1단계 → 2단계 → 3단계 → 결과. 각 단계에는 "건너뛰기"를 두고, 목표 체류 시간은 단계마다 3~4분이다.
- 화면 해상도 기준 1920×1080 가로, 터치. 최소 글자 크기 24px.
- 120초 동안 입력이 없으면 시작 화면으로 돌아가고 상태를 초기화한다.
- 교사 설정 화면: 화면 왼쪽 위 모서리를 3초 길게 누르면 열린다. 시드 고정, σ, 학습 점 수, 기록 초기화, 오늘 기록 CSV 내보내기를 제공한다.
- 폰트: 시스템 한글 폰트를 우선 쓴다. 폰트를 번들한다면 라이선스(OFL 등)를 확인하고 `public/fonts`에 둔다.
- 색만으로 정보를 구분하지 않는다(학습 점은 원, 검증 점은 다이아몬드처럼 모양도 다르게).
